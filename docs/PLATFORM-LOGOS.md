# Platform logo assets

These locally served vectors identify operating systems and browsers in the marketing page’s Supported strip. They are third-party brand marks, not Office & Cloud branding.

## Sources

| Asset | Source | Local treatment |
| --- | --- | --- |
| `public/brand/platforms/windows.svg` (Windows) | [Pinned upstream SVG](https://raw.githubusercontent.com/devicons/devicon/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6/icons/windows11/windows11-original.svg) | Unchanged vector. |
| `public/brand/platforms/apple.svg` (Apple / macOS) | [Pinned upstream SVG](https://raw.githubusercontent.com/devicons/devicon/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6/icons/apple/apple-original.svg) | Near-white fill for the dark background; original vector paths retained. |
| `public/brand/platforms/linux.svg` (Linux / Tux) | [Pinned upstream SVG](https://raw.githubusercontent.com/devicons/devicon/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6/icons/linux/linux-plain.svg) | Near-white fill for the dark background; original vector paths retained. |
| `public/brand/platforms/chrome.svg` (Google Chrome) | [Pinned upstream SVG](https://raw.githubusercontent.com/alrra/browser-logos/58881b84c4d73adc03c06fa2c275a7abee02d935/src/chrome/chrome.svg) | Unchanged vector. |
| `public/brand/platforms/edge.svg` (Microsoft Edge) | [Pinned upstream SVG](https://raw.githubusercontent.com/alrra/browser-logos/58881b84c4d73adc03c06fa2c275a7abee02d935/src/edge/edge.svg) | Unchanged vector. |
| `public/brand/platforms/firefox.svg` (Mozilla Firefox) | [Pinned upstream SVG](https://raw.githubusercontent.com/alrra/browser-logos/58881b84c4d73adc03c06fa2c275a7abee02d935/src/firefox/firefox.svg) | Unchanged vector. |
| `public/brand/platforms/safari.svg` (Apple Safari) | [Pinned upstream SVG](https://raw.githubusercontent.com/alrra/browser-logos/58881b84c4d73adc03c06fa2c275a7abee02d935/src/safari/safari.svg) | Unchanged vector. |

The Windows, Apple and Tux vectors come from [Devicon](https://github.com/devicons/devicon/tree/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6). Browser vectors come from [Browser Logos](https://github.com/alrra/browser-logos/tree/58881b84c4d73adc03c06fa2c275a7abee02d935). The lightweight monochrome Tux variant retains the upstream silhouette. All assets have transparent backgrounds and local-only SVG references.
